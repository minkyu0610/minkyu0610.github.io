## 도구

### 메이플 환산 대시보드 — [`/maple/`](https://minkyu0610.github.io/maple/)

캐릭터를 매번 이름으로 검색하지 않고, 등록해둔 목록을 한 번에 조회하는 대시보드.

**쓰는 법**

1. [openapi.nexon.com](https://openapi.nexon.com/my-application/) 에서 넥슨 오픈 API 키 발급
   (넥슨 로그인 → 내 애플리케이션 → 앱 등록 → 메이플스토리 선택)
2. 페이지 상단 **설정**에 키 입력 후 저장
3. 캐릭터명 등록 → **전체 새로고침**

**구성**

- **표** — NEXON Open API 원본값 (전투력 · 유니온 · 무릉 · 주스탯 · 공격력 · 보공 · 방무 · 크뎀 · 최종뎀)
- **뷰어** — 캐릭터 클릭 시 maplescouter의 **환산 / 보스컷 / 스펙업 순서 / 헥사강화** 페이지를 그대로 표시.
  탭별로 화면 잘라내기(위·좌·폭·확대·높이)를 따로 저장한다.

**알아둘 것**

표의 수치는 게임 내 변동이 평균 15분 뒤 반영되고, 장비 프리셋과 버프 상태에 따라 달라진다.
같은 캐릭터도 날짜에 따라 전투력이 20% 이상 차이날 수 있어 절대 비교보다 추세 확인에 적합하다.

환산 주스탯은 직접 계산하지 않는다. 스탯창 값만으로는 직업별 스킬 계수를 반영할 수 없어
실측 대비 최대 3배까지 어긋나는 것을 확인했고, maplescouter가 계산한 값을 그대로 보여준다.

## 저장되는 것

API 키와 설정은 각 도구의 브라우저 localStorage에만 저장된다.
이 저장소에는 키가 포함되지 않으며, 넥슨 API 외 다른 서버로 데이터가 나가지 않는다.
